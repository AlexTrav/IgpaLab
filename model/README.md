# model: прогноз IGPA

Признаки, протокол проверки и модели прогноза IGPA следующего учебного года (задача A) и риска его снижения на 0,1 и больше (задача B). Дизайн и выводы: [docs/research.md](../docs/research.md).

## Запуск

```
make -C model baselines   # B0 и B1: results/v1/baselines и контроль results/v1/baselines_disjoint
make -C model models      # Ridge, RF, CatBoost, стекинг, среднее, контроль прогноза уровня: results/v1/models
make -C model series      # серии S0–S3 на CatBoost (вклад групп признаков): results/v1/series
make -C model hybrid      # своя модель IGPA-Hybrid и серия S8 (смена правил): results/v1/hybrid
make -C model recsys      # SHAP, восстановление эффектов, рекомендации, серия S7: results/v1/recsys
make -C model export      # финальные модели для сайта и данные стенда: artifacts/v1 (~2 мин на правило)
make -C model export-research   # только research.json для сайта (без обучения), после новых проверок
make -C model check NAME=light  # проверки надёжности: light, learning, scenarios, semester, open-uci, robust (results/v1/checks)
make -C model models ARGS=--disjoint   # контроль с непересекающимися студентами: results/v1/models_disjoint
make -C model test        # 30 тестов: нет утечки из будущего, порядок проверок, метрики, устройство моделей
```

## Устройство

| Файл | Что делает |
| --- | --- |
| `forecast/features.py` | Панель «студент × год»: признаки года t (оценки, достижения, лаги, поведение в АСУ, контекст) и цели года t+1 |
| `forecast/protocol.py` | Расширяющееся окно по времени, метрики, бутстреп-ДИ по студентам, Уилкоксон, Холм |
| `forecast/baselines.py` | B0 «IGPA не изменится», B1 «только GPA» |
| `forecast/hybrid.py` | IGPA-Hybrid: компоненты (GPA, число записей по 16 типам, уровни), розыгрыши и точный пересчёт калькулятором igpa |
| `forecast/recommend.py` | Рекомендации «что если»: точный прирост по калькулятору, реалистичность по похожим студентам, проверка следованием |
| `forecast/study.py` | Шаг 7: SHAP, восстановление эффектов, серия S7, рисунки 7–9, отчёт |
| `forecast/export.py` | Финальное обучение для сайта: облегчённые модели (ручной ввод), полные (студенты стенда), гибрид, реалистичность, сводка исследования |
| `forecast/models.py` | Ridge и логистическая регрессия, Random Forest, CatBoost; стекинг (NNLS-веса и логистическая мета-модель) и простое среднее; кэш обученных моделей |
| `forecast/evaluate.py` | Прогон моделей: 2 правила × 2 слоя × 3 проверочных года; итог по последнему году |
| `forecast/report.py` | Отчёт прогона в Markdown |

Протокол:

- проверочные годы t = 2022, 2023, 2024 (переходы в 2023/24, 2024/25, 2025/26), обучение на всех более ранних переходах; основная проверка – последняя (2 492 перехода);
- переход (t−1 → t) в обучении законен: к моменту прогноза итоги года t известны; контрольный прогон `--disjoint` исключает студентов проверки из обучения совсем;
- порог риска выбирается по F1 на последнем году обучающей части, затем модель переобучается на всей обучающей части (в первой проверке год один – порог по обучающим данным);
- MAE разных слоёв не сравниваются напрямую: у слоя АСУ своя цель (IGPA, каким его увидит АСУ).

Каждый прогон пишет в `results/<версия>/<имя>/`: `report.md`, `summary.csv`, `folds.csv`, `predictions.parquet`.

Модели регрессии учат изменение IGPA (прогноз = IGPA года t + изменение); `CatBoost-level` – контроль с прогнозом уровня. Параметры подбираются по сетке на последнем году обучающей части: Ridge – сила регуляризации, лес – размер листа и доля признаков (500 деревьев), CatBoost – глубина и L2 с ранней остановкой. Серии: S0 – оценки и контекст, S1 – плюс достижения и поведение в АСУ, S2 – все признаки с динамикой, S3 – все без одной группы; параметры CatBoost в сериях подбираются один раз на полном наборе (S2) и общие для всех вариантов.

IGPA-Hybrid прогнозирует не IGPA, а то, из чего он складывается, причём не зависящее от правил расчёта: изменение GPA (CatBoost), число записей следующего года по каждому из 16 типов (CatBoost с пуассоновской функцией потерь), уровни записей (история студента в типе, сглаженная к вузу). Затем 200 розыгрышей записей и GPA (с ошибкой GPA из валидации); IGPA каждого розыгрыша считает калькулятор igpa. Прогноз – среднее, риск – доля розыгрышей со снижением на 0,1 и больше. При смене правил компоненты те же, меняется только калькулятор (серия S8).
