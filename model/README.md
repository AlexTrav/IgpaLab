# model: прогноз IGPA

Признаки, протокол проверки и модели прогноза IGPA следующего учебного года (задача A) и риска его снижения на 0,1 и больше (задача B). Дизайн и выводы: [docs/research.md](../docs/research.md).

## Запуск

```
make -C model baselines   # B0 и B1: results/v1/baselines и контроль results/v1/baselines_disjoint
make -C model test        # 16 тестов: нет утечки из будущего, порядок проверок, метрики
```

## Устройство

| Файл | Что делает |
| --- | --- |
| `forecast/features.py` | Панель «студент × год»: признаки года t (оценки, достижения, лаги, поведение в АСУ, контекст) и цели года t+1 |
| `forecast/protocol.py` | Расширяющееся окно по времени, метрики, бутстреп-ДИ по студентам, Уилкоксон, Холм |
| `forecast/baselines.py` | B0 «IGPA не изменится», B1 «только GPA» |
| `forecast/evaluate.py` | Прогон моделей: 2 правила × 2 слоя × 3 проверочных года; итог по последнему году |
| `forecast/report.py` | Отчёт прогона в Markdown |

Протокол:

- проверочные годы t = 2022, 2023, 2024 (переходы в 2023/24, 2024/25, 2025/26), обучение на всех более ранних переходах; основная проверка – последняя (2 492 перехода);
- переход (t−1 → t) в обучении законен: к моменту прогноза итоги года t известны; контрольный прогон `--disjoint` исключает студентов проверки из обучения совсем;
- порог риска выбирается по F1 на последнем году обучающей части, затем модель переобучается на всей обучающей части (в первой проверке год один – порог по обучающим данным);
- MAE разных слоёв не сравниваются напрямую: у слоя АСУ своя цель (IGPA, каким его увидит АСУ).

Каждый прогон пишет в `results/<версия>/<имя>/`: `report.md`, `summary.csv`, `folds.csv`, `predictions.parquet`.
