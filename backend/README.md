# backend: API стенда

FastAPI поверх калькулятора `igpa` и сохранённых моделей `model/artifacts/v1` (их готовит `make -C model export`). Кода обучения в образе нет: только загрузка моделей и расчёт.

## Запуск

```
make -C model export    # один раз: финальные модели и данные для сайта
make -C backend run     # http://localhost:8000, документация /docs
make -C backend test    # тесты всех точек API на настоящих артефактах
```

## Точки

| Запрос | Режим сайта | Что делает |
| --- | --- | --- |
| `GET /api/meta?lang=` | все | 16 типов и 9 статусов АСУ на ru, kk, en, правила, факультеты |
| `POST /api/quick` | «Быстрый расчёт» | GPA, iROS, SSCI → IGPA по трём правилам с разложением |
| `POST /api/calc` | «Мой портфель» | GPA и список записей → IGPA по калькулятору, вклады типов, флаги записей |
| `POST /api/portfolio` | «Мой портфель» | IGPA сейчас; прогноз IGPA-Hybrid на следующий год (среднее, 10–90%, вероятность снижения на 0,1); второй прогноз облегчённого CatBoost; SHAP; 3 совета с точным приростом, реалистичностью и текстом |
| `GET /api/students` | «Студент со стенда» | Поиск синтетических студентов (по умолчанию – кто учится сейчас) |
| `GET /api/students/{id}?rules=&lang=` | «Студент со стенда» | История по годам, записи АСУ, прогноз против факта на 2025/26, прогноз на 2026/27 с коридором и SHAP |
| `GET /api/research` | страницы исследования | Сводка результатов шагов 4–7 |

Ввод портфеля: `gpa`, `gpa_prev` (необязательно), `year_of_study`, `level` (`bachelor`, `master_research`, `master_profile`), `records` (`category`, `status` – коды справочника), `rules` (`default`, `eduscore`, `percentile`), `lang` (`ru`, `kk`, `en`).

Модели для ручного ввода – облегчённые: учатся только на том, что человек может ввести (GPA, GPA прошлого года, курс, уровень, записи). Их качество против полной модели – в `research.light_eval`.
