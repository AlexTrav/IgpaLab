# research: анализ данных

Разведочный анализ синтетического датасета: состав IGPA при двух правилах нормировки, полнота АСУ, динамика год к году, связь признаков с будущим IGPA, предварительная проверка гипотезы H0, сценарий «как в жизни». Выводы для моделей: [docs/research.md](../docs/research.md), раздел «Выводы анализа данных».

## Запуск

```
make -C research report   # results/v1: report.md, numbers.json, figures/ru и figures/en
make -C research test     # 6 тестов: панель «студент × год» без сдвигов, счётчики, определение риска
```

## Рисунки

| Файл | Что показывает |
