# igpa: калькулятор IGPA

Считает iROS, SSCI и IGPA по записям достижений студента так, как предписывает Положение «Туран» (П УТ 811–06–25, ред. 28.08.2025), на справочниках формы АСУ «ТУРАН» 2026/27. Один калькулятор на весь стенд: им пользуются генератор синтетики, модели и рекомендации. Обоснование правил и допущений: [docs/igpa-rules.md](../docs/igpa-rules.md).

## Состав

| Файл | Что внутри |
| --- | --- |
| `igpa/catalog.py` | 16 типов мероприятий (колонки J–Y выгрузки) и 9 статусов АСУ, поиск по тексту |
| `igpa/presets/default.yaml` | Правила стенда: Положение и допущения для новых типов АСУ |
| `igpa/presets/eduscore.yaml` | Правила движка EduScore для сверки с дипломным проектом |
| `igpa/presets/percentile.yaml` | Серия S7: Положение с потолком нормировки по 95-му процентилю (iROS 0,08, SSCI 0,20) |
| `igpa/rules.py` | Загрузка и проверка правил |
| `igpa/calc.py` | Расчёт и флаги качества записей |

## Переключатели правил

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `method` | `category`: в каждом типе до 5 лучших записей, доля от 100 баллов, веса блока в сумме 1 (п. 3.6, 3.7); `eduscore`: 5 лучших эффективных баллов по направлению, деление на максимум | `category` |
| `ssci_blocks` | `mean`: среднее разовой и постоянной частей; `sum_clip`: сумма, обрезанная до 1 | `mean` |
| `foreign_status` | `map`: статус чужой карты сопоставляется по `status_map`; `reject`: запись не учитывается | `map` |
| `only_approved` | учитывать только согласованные записи | `true` |
| `scale` | множитель iROS и SSCI в формуле (4: шкала GPA, как в EduScore) | `4` |
| `category_weights` | веса типов; 0 исключает тип из расчёта | Положение и допущения |
| `ceiling_iros`, `ceiling_ssci` | потолок нормировки: iROS = min(1, iROS / потолок) | 1 (без потолка) |

Поменять правило для эксперимента: `load_rules().with_changes(ssci_blocks="sum_clip")`, правила проверяются заново.

## Пример

```python
from igpa import Record, calculate

result = calculate([
    Record("IROS_PUBLICATION", "IROS_INT_RK"),
    Record("SSCI_STUDENT_ORG", "SSCI_PERMANENT"),
    Record("SSCI_SPORT", "SSCI_PERMANENT"),          # статус не подходит типу: не учтена, флаг status_mismatch
], gpa=3.4)
result.igpa, result.iros, result.ssci                # IGPA по шкале 0–4, iROS и SSCI в долях от 1
result.categories["IROS_PUBLICATION"].contribution   # вклад типа в iROS
result.flags                                         # что не учтено и почему
```

Период (учебный год, семестр) выбирает вызывающий код: в `calculate` передаются записи одного периода.

## Флаги записей

| Флаг | Когда |
| --- | --- |
| `not_approved` | запись не согласована |
| `no_rule` | у типа нулевой вес |
| `status_mapped` | статус чужой карты сопоставлен со своим |
| `status_mismatch` | статус не подходит типу, запись не учтена |
| `over_limit` | сверх пяти лучших или сверх максимума типа |
