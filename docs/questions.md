# Вопросы и чего не хватает

Обновлено 06.11.2026. Отвеченное переносится в [decisions.md](decisions.md).

## Спросить у научного руководителя (07.11.2026)

| Вопрос | Рабочее допущение до ответа |
| --- | --- |
| Есть ли новая редакция Положения или приложений с весами для «Выступление с докладом», «Научная стажировка», «Руководство в студенческих организациях», «Волонтёрство в структурных подразделениях»? Скорее всего нет | См. [igpa-rules.md](igpa-rules.md), раздел «Допущения для новых категорий» |
| Как АСУ считает «Общий балл по IROS/SSCI» и баллы по категориям: сырые баллы, с весом, нормировано в 0–1, шкала 0–4? Хватит одной обезличенной строки или скриншота | Баллы по категориям: сырая сумма до 5 лучших; общий балл: коэффициент 0–1 |
| Будет ли в реальных данных GPA по семестрам и выгрузки на несколько дат (или записи с датами)? | GPA по семестрам и история генерируются; план на случай «нет» в [data.md](data.md) |
| Можно ли получать ту же выгрузку IGPA регулярно (раз в месяц или на конец семестра), чтобы копить историю? | Нет |
| Предел в 5 достижений: по категории (буквально Положение) или по направлению (как в EduScore)? | По категории, переключатель в конфиге |
| Как SSCI сводит разовую часть (сумма весов 1) и постоянную (сумма весов 1)? | Среднее двух частей |
| Какой GPA входит в IGPA: годовой, семестровый или накопленный? | Годовой, накопленный как признак |
| Сводная по IROS считает студентов или записи? | Студентов |

## К пользователю

| Вопрос | Рабочее допущение |
| --- | --- |
| Название проекта и репозитория | Варианты в ответе 06.11.2026, ждёт выбора |
| Корень репозитория: сама папка `pre-project` или подпапка `pre-project/<Название>` (как `project/SmogCast`) | Подпапка, docs и data переносятся в неё |
| Объём синтетики | 2500 студентов, бакалавриат и магистратура, история с осени 2021 |
| Список факультетов и ОП «Туран» | Взять с сайта университета |
| Языки сайта | ru, kk, en, как в прошлых проектах (en нужен для скриншотов в статье) |
| Ключ OpenAI для текста рекомендаций | В стенде шаблоны текста; LLM опционально через переменную окружения |

## Отвечено

- Расхождение категорий АСУ и Положения нормальное: АСУ новее (06.11.2026).
- Горизонт прогноза: учебный год основной, семестр дополнительный (06.11.2026).
- Справочники «тип» (16) и «статус» (9) из формы АСУ: в [igpa-rules.md](igpa-rules.md) (06.11.2026).
- Научный руководитель: Муканова Жанна Аскаровна; pre-project: мини-проект, сайт-стенд с прогнозом и рекомендациями (06.11.2026).
- Код в отдельном репозитории, пока локально в этой папке, нужно новое название (06.11.2026).

## Чего не хватает в материалах

- Реальной выгрузки (ожидается, сроки неизвестны).
- Источника GPA и истории по периодам.
- Шаблона IEEE (скачать при подготовке статьи).
