## Что входит в pre-project

Первая итерация системы, от научного руководителя:

- заметки по магистерской и статья (статья в конце, под IEEE DG 2027);
- система прогнозирования IGPA и рекомендаций по его повышению;
- синтетический датасет как лабораторный стенд: генерация истории студентов, на её основе рекомендации;
- 2–3 открытых алгоритма, их смешивание (ансамбль) и своя модель.

Реальная выгрузка из АСУ не собрана, поэтому научный руководитель сказала строить подробный синтетический датасет по двум шаблонам выгрузки АСУ (`data/example`): в них все поля будущего реального датасета.

Форма сдачи: мини-проект, простой сайт-лабораторный стенд, где можно получить прогноз IGPA и рекомендации. По теме магистерской, но без лишнего; детали определяем, когда будут готовы движок и данные.

Проект: отдельный репозиторий (новое название выбирается), пока всё локально в этой папке. Стек как в SmogCast и KinoCompass: Python 3.12, FastAPI, scikit-learn, CatBoost, SHAP, pytest; Vue 3, TypeScript, Tailwind 4, vue-i18n, ECharts, @vueuse, lucide; Docker на каждый модуль, Makefile, GitHub Actions; сайт на GitHub Pages, API на Render.

## Технические правила

- Всё запускается только в Docker: никаких локальных `.venv` и `node_modules`.
- Репозиторий https://github.com/AlexTrav/IgpaLab (приватный). Коммит и пуш после каждого шага: по-русски, в прошедшем времени, без соавторства, личная noreply-почта.
- Каждый шаг: план на одобрение, реализация, проверка (как в SmogCast и KinoCompass).
- Модели обучаются там, где выгоднее: табличные на CPU в Docker, Colab только при нужде в GPU.
- Во всех файлах только среднее тире «–», длинное не использовать.
- Цифр точности на реальных данных не придумывать: их пока нет.
- В шаблонах АСУ в шапке есть ФИО сотрудника, сформировавшего выгрузку. В синтетике и в любых публичных материалах реальных ФИО быть не должно.

```
<Название>/
  docs/        дока (эта папка)
  igpa/        калькулятор IGPA: справочники АСУ, Положение, допущения в конфиге; общий для всех модулей

  backend/     FastAPI: расчёт IGPA, прогноз, риск, рекомендации «что если», данные стенда
  frontend/    сайт-стенд
  .github/workflows/, render.yaml, Makefile, README.md, LICENSE
```
