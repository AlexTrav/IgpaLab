# IgpaLab

Лабораторный стенд прогнозирования интегрального GPA (IGPA) студентов и рекомендаций по его повышению. Pre-project магистерской диссертации «Разработка и исследование интеллектуальной системы анализа и прогнозирования образовательных достижений обучающихся на основе интегрального GPA» (Университет «Туран»).

Реальная выгрузка из АСУ пока не собрана, поэтому стенд работает на синтетических данных в формате выгрузок АСУ «ТУРАН» (`data/example`). Когда придут реальные данные, меняется только загрузчик.

## Состав

| Папка | Что внутри | Состояние |
| --- | --- | --- |
| [docs/](docs/) | Рабочая документация: правила IGPA, данные, дизайн исследования, статья, вопросы, решения | Ведётся |
| [igpa/](igpa/) | Калькулятор IGPA по Положению и справочникам АСУ | Готов |
| [data/](data/) | Шаблоны выгрузок АСУ, генератор синтетики, версия v1 (6000 студентов) | Готов |
| [research/](research/) | Анализ данных: отчёт и рисунки ru/en | Готов |
| [model/](model/) | Прогноз IGPA: признаки, протокол проверки, базовые уровни | В работе |
| backend/, frontend/ | API, сайт | Впереди |

## Запуск

Всё работает в Docker, локальные окружения не нужны: Docker Desktop и make.

```
make test          # все автотесты
make data          # сгенерировать синтетический датасет data/synthetic/v1
make report        # анализ данных: research/results/v1
```
