# IgpaLab

Лабораторный стенд расчёта, прогноза и рекомендаций по интегральному GPA (IGPA) студентов. Pre-project магистерской диссертации «Разработка и исследование интеллектуальной системы анализа и прогнозирования образовательных достижений обучающихся на основе интегрального GPA» (Университет «Туран», ОП 6М06102; автор – Нерезов А. К., научный руководитель – Муканова Ж. А.).

**Сайт:** https://alextrav.github.io/IgpaLab/ · **API:** https://igpalab-backend.onrender.com/docs (бесплатный Render засыпает, первый ответ – около минуты)

IGPA = 0,5 · GPA + 0,35 · iROS · 4 + 0,15 · SSCI · 4 (Положение «Туран», 2025). Реальной выгрузки АСУ у проекта пока нет, поэтому стенд работает на синтетическом вузе в формате выгрузок АСУ «Туран» (`data/example`); когда придут реальные данные, меняется только загрузчик.

## Что умеет сайт

- **Мой портфель** – ввод GPA и достижений как в АСУ (16 типов, 9 статусов); IGPA по трём правилам (Положение, схема EduScore, потолок 95%), прогноз на следующий учебный год своей моделью IGPA-Hybrid с коридором 10–90% и риском снижения, объяснение SHAP, три совета с точным приростом и реалистичностью.
- **Студент со стенда** – любой из 6 000 синтетических студентов: история IGPA по годам, записи АСУ, прогноз и проверка прогноза прошлого года против факта.
- **Быстрый расчёт** – IGPA по трём числам выгрузки и обратный расчёт «какой GPA нужен».
- **Исследование** – модели с доверительными интервалами, смена правил без переобучения, вклад признаков, правила и советы, семь проверок надёжности, данные и методика.
- Три языка (русский, казахский, английский), светлая и тёмная тема, подсказки «?» у терминов, «Поделиться» картинкой, офлайн-режим (PWA).

## Главные результаты

На последней проверке по годам (обучение до 2024/25, прогноз 2025/26 для 2 492 студентов):

- модели точнее прогноза «IGPA не изменится» (B0) на 12–14%, различия значимы (Уилкоксон с поправкой Холма); ROC-AUC риска снижения 0,72–0,79;
- Ridge, CatBoost, смеси и IGPA-Hybrid между собой почти равны; гибрид переходит на новые правила одной заменой калькулятора;
- по Положению достижения объясняют около 5% разброса IGPA, по EduScore около 25%, с потолком 95% около 49%: правило нормировки решает больше, чем модель;
- выводы держатся на трёх вариантах синтетики (в том числе с участием как в реальном исследовании AITU), на непересекающихся студентах и подтверждаются на открытых данных UCI.

Подробно – [docs/research.md](docs/research.md).

## Запуск

Всё работает в Docker: нужны только Docker Desktop и make, локальные окружения (venv, node_modules) не нужны.

```
make test          # все автотесты (6 модулей)
make data          # сгенерировать синтетический датасет data/synthetic/v1
make report        # анализ данных: research/results/v1
make export        # финальные модели для сайта: model/artifacts/v1
make api           # API на http://localhost:8000 (документация /docs)
make site          # сайт на http://localhost:8080 с локальным API (вместе с make api)
```

Команды каждого модуля – в его README.

## CI/CD

- [CI](.github/workflows/ci.yml): на каждый push в main и pull request – тесты всех шести модулей параллельно, в тех же Docker-образах, что и локально.
- [Pages](.github/workflows/pages.yml): после зелёного CI сайт собирается с базовым путём `/IgpaLab/` и API на Render и публикуется на GitHub Pages.
- [Render](render.yaml): API (бесплатный план, Франкфурт) пересобирается только при изменении API, калькулятора или артефактов моделей и только после зелёного CI; запросы разрешены только с адреса сайта.
